# Game reference — generated

These pages were first a snapshot of the Unity tool `Tools > Docs > Export Game Reference` (the Unity content on
2026-10-15, the day the Godot build became the game). They are now generated from the live content
(`data/content/` in this repo) by `tools/game_reference.gd`
(`godot --headless --path . -s tools/game_reference.gd`; same sections as the Unity export, numbers through the
AssetConverter). Regenerate them after content changes and commit them with the content; do not edit them by hand.
